# Sistema de Votação em Java

Mini-projeto desenvolvido para as disciplinas de Lógica de Programação II e Programação Orientada a Objetos — Java.

## Objetivo

O sistema foi desenvolvido para realizar uma votação escolar para escolher uma atividade especial para a Semana da Tecnologia.

O programa permite:

- Cadastrar candidatos;
- Registrar votos por turma;
- Exibir a matriz de votos;
- Calcular o total de votos;
- Calcular o percentual de cada candidato;
- Identificar o vencedor;
- Identificar situações de empate.

## Limites do sistema

- Até 5 candidatos;
- 3 turmas;
- Até 10 votantes por turma;
- O número 0 encerra a votação da turma.

## Conceitos utilizados

O projeto utiliza:

- while;
- do-while;
- for;
- break;
- continue;
- Arrays unidimensionais;
- Arrays bidimensionais (matrizes);
- Loops aninhados;
- Validação de entradas;
- Busca de candidatos;
- Cálculo de porcentagens.
